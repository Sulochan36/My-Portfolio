## Overview

`useRef` and `useState` are both hooks in React, but they behave differently.

- `useState` triggers re-render on change.
- `useRef` persists a value without causing re-render.

### Example

```js
const count = useRef(0)
const [stateCount, setStateCount] = useState(0)
